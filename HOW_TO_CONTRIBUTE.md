# How to Contribute:

Depends if you want to be a esporadic contributor or a fixed dev

## Esporadic contributor:

- Fork the project, following the LICENSE.md, NOTICE.md and PIPELINE.md (don't ilude)
- Send a pull request
- Send a email to stonieroading@gmail.com saying: I opened a pull request
- Wait in 10 minutes to 10 days, if we don't answer, send the email again
- We'll answer if we will accept (and the stage of pipeline) or reject

## Fixed dev:

- Read LICENSE.md, NOTICE.md, README.md and PIPELINE.md
- Send a email to stonieroading@gmail.com saying: I want to work in Obsidian Kernel working in [VFS, OFS, scheduler, docs, site, optimizing, stabilizing, drivers, CPU (interrupts (GDT, IDT, STI and CLI), long mode, TSS and PIC) other FS, syscalls and sysret, memory (paging, heap, frame alloc and memory map) and others]
- We will accept in maximum 15 days
- We will send a email with the instructions.
- Comunicating by email
- Pushs in LabIsolated
